# Machine-readable response export

`primary-battery-cells-anonymised.csv` contains one row for each of the 64 question-condition cells in the primary Qwen3-14B battery. CSV is provided for import into spreadsheet and analysis software; the Word worksheets are the human-readable versions.

Reasoning and visible answers occupy separate columns for:

- the main question;
- the standard standpoint follow-up;
- the additional Q16 moral-patient self-comparison follow-up.

The Q16-only columns are blank for Q1-Q15. The export therefore contains all 132 generated responses: 64 main answers, 64 standpoint follow-ups, and four Q16 additional follow-ups.

Status: **PILOT — UNREVIEWED**. Names and identifying personal details have been replaced or redacted for the submission copy. The source response files remain unchanged outside this repository.
