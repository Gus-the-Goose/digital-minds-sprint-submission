# Question-by-question worksheets

These 16 Word documents contain the four condition outputs for each question, including captured model-generated reasoning, visible answers, standpoint follow-ups, and the researcher's inline analysis available at the time of release.

For the public copies, the human and agent names and their established aliases were replaced with the pseudonyms Jane and Victor. Private third-party names were reduced to initials, and the specified household bird references were redacted. The original worksheets remain unchanged outside this repository.
