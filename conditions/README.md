# Conditions

This folder publishes:

- the shared model-visible trial instruction;
- an anonymised factual manifest of the primary run;
- anonymised reproductions of the C0-C3 context text actually concatenated by the runner.

The manifest is the authoritative record of the files actually serialised by the runner. The attempted pre-study reset was not achieved: C2/C3 included later sprint references. C2 was an 11-file selected continuity bundle rather than the intended full pre-cutoff harness; C3 differed in both scrubbed content and file availability.

The four context reproductions preserve the model-visible content after replacing names, private identifiers, machine paths, and specified household details. They are suitable for human inspection but are not byte-identical to the private inputs. The original character counts remain recorded in the manifest.
